# User Stories — Akıllı Klinik Yönetim Sistemi

## 👨‍⚕️ Doctor (Doktor) User Stories

**US-D01** — As a **doctor**, I want to **log in to the system with my credentials**, so that **I can securely access my portal**.

**US-D02** — As a **doctor**, I want to **view my daily appointment list**, so that **I can plan my day efficiently**.

**US-D03** — As a **doctor**, I want to **see patient details before the appointment**, so that **I can review their medical history in advance**.

**US-D04** — As a **doctor**, I want to **write a prescription for a patient after the appointment**, so that **the patient receives the correct medication**.

**US-D05** — As a **doctor**, I want to **set my available time slots**, so that **patients can only book appointments at times I am free**.

**US-D06** — As a **doctor**, I want to **mark an appointment as completed or cancelled**, so that **the system stays up to date**.

**US-D07** — As a **doctor**, I want to **search for a specific patient by name or ID**, so that **I can quickly access their records**.

---

## 🧑‍🤝‍🧑 Patient (Hasta) User Stories

**US-P01** — As a **patient**, I want to **register to the system with my name, email, and phone number**, so that **I can book appointments**.

**US-P02** — As a **patient**, I want to **log in using my email and password**, so that **I can access my personal portal**.

**US-P03** — As a **patient**, I want to **search for doctors by name or specialty**, so that **I can find the right doctor for my needs**.

**US-P04** — As a **patient**, I want to **view a doctor's available time slots**, so that **I can choose a convenient appointment time**.

**US-P05** — As a **patient**, I want to **book an appointment with a doctor**, so that **I can receive medical care**.

**US-P06** — As a **patient**, I want to **view all my past and upcoming appointments**, so that **I can keep track of my healthcare**.

**US-P07** — As a **patient**, I want to **cancel an appointment**, so that **the doctor's time slot becomes available for others**.

**US-P08** — As a **patient**, I want to **view my prescriptions**, so that **I know which medications I have been prescribed**.

---

## 🛠️ Admin (Yönetici) User Stories

**US-A01** — As an **admin**, I want to **log in to the admin panel with a secure username and password**, so that **I can manage the system**.

**US-A02** — As an **admin**, I want to **add a new doctor to the system**, so that **patients can book appointments with them**.

**US-A03** — As an **admin**, I want to **remove or deactivate a doctor**, so that **inactive doctors no longer appear in searches**.

**US-A04** — As an **admin**, I want to **view all registered patients**, so that **I can monitor system usage**.

**US-A05** — As an **admin**, I want to **view all appointments in the system**, so that **I can track clinic activity**.

**US-A06** — As an **admin**, I want to **generate daily, monthly, and yearly appointment reports**, so that **I can analyse clinic performance**.

**US-A07** — As an **admin**, I want to **view which doctor has the most patients**, so that **I can manage workload distribution**.

**US-A08** — As an **admin**, I want to **manage user accounts (reset passwords, activate/deactivate)**, so that **the system remains secure and functional**.
